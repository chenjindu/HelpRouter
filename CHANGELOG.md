# Changelog

All notable changes to HelpOS Router Edition are documented here.

## [1.0.0] — 2026-08-31

First public release of **HelpOS Router Edition** (Raspberry Pi 5, arm64).

### Included

- WiFi repeater + dual-band (2.4G + 5G) hotspot, running simultaneously
- Fixed-IP DHCP, MAC clone
- Remote access: free `*.hc.ink` subdomain, DDNS + tunnel (works behind NAT/CGNAT)
- DNS filtering: ads, malware/phishing, adult content
- VPN server & client (WireGuard, OpenVPN)
- 8 built-in services: SSH, SMB, FTP, Git, SVN, DNS, Web, File
- Local Share: browser-based cross-device text & file sharing
- Full web UI, web terminal, one-click upgrade, backup & restore
- Watchdogs for upstream WiFi reconnection and USB adapter recovery
